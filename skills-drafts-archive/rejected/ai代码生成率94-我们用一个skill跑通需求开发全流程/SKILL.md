# AI代码生成率94%：我们用一个Skill跑通需求开发全流程 — 可执行规则

## 规则

1. 知识库分三级：L1总览(<5KB) + L2模块(按需加载) + L3语义桥(精确映射)
2. 定位先看目录和文件名，再grep，最后才读代码
3. 任何"长跑命令"都不靠stdout报告成功，全靠落盘文件
4. 红线触发即停，按模板报告，不允许继续
5. 编译验证：退出码0是唯一判据，自修复上限3轮
6. 禁止LLM手工分桶，必须先用脚本处理数据

## 关联skill
- debug-flow（五步定位法可增强）
- deploy-checker（编译验证+模拟器验证可参考）
- 建议新建：knowledge-base-manager（三级知识库管理）
- 建议新建：redline-system（红线机制）
