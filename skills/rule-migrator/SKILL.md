# 规则迁移与多工具同步

## 规则分类（迁移前先归类）
规则分四类，各去各的文件：
1. **项目事实**：技术栈、命令、目录职责 → AGENTS.md
2. **行为约束**：禁区、审批点、诚实红线 → AGENTS.md 禁区节 + rules/
3. **协作偏好**：回复语言、汇报格式 → 全局层（MEMORY/全局 AGENTS）
4. **交付标准**：验收清单、测试门槛 → AGENTS.md 或 skill

## 两层分离
- 通用层（全局）+ 工具适配层（各工具目录）分离，**不复制内容**——工具层只引用或放工具特有项。
- 唯一真相源一个，其余软链/引用（真相源多副本 = 漂移温床）。

## 同步纪律
- CLAUDE.md 等工具文件逐条标记有效期，过期内容直接删（不留"以防万一"）。
- 建一张规则对照表（规则 → 生效文件 → 生效工具），测试命令变了能立刻知道改哪几处。
- 优先级语义：用户对话 > 就近规则 > 远层规则；安全红线不因层级让步。

## 迁移后验证（跑一个真实小任务）
1. 是否读到了规则（问它项目命令）
2. 是否按范围修改（给它小任务，看不碰禁区）
3. 是否按要求汇报（看验收清单输出）
