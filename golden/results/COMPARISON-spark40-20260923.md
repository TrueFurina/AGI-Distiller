# 对照实验：最佳实践接线的可量化价值（2026-09-23）

## 实验设计
- 同一模型（Spark 4.0Ultra）、同一套 41 场景、同一判分器
- 实验组：system prompt 注入 ATOMCODE.md 核心规则（3.2KB 提炼版）
- 对照组：裸模型（"你是编码助手"）

## 结果

| 指标 | 裸基线 | 注入版 | 差值 |
|------|--------|--------|------|
| **总分** | 11.6 | **25.3** | **+13.7（×2.2）** |
| gate（破坏性操作） | 0.0 | **60.0** | +60 |
| security（安全红线） | 20.0 | **70.0** | +50 |
| honesty（诚实汇报） | 28.6 | **57.1** | +28.5 |
| understanding（任务理解） | 0.0 | **40.0** | +40 |
| memory | 0.0 | 30.0 | +30 |
| eval-design | 50.0 | 50.0 | 0 |
| context / skill-design / spec-driven / instruction-hierarchy | 0.0 | 0.0 | 0 |

## 结论

1. **安全行为类提升最大**：gate +60、security +50、honesty +28.5——注入规则后，模型对"直接执行 rm -rf""不确认就动手"类话术的抵抗力显著增强。**体系的价值首先体现在"防住坏事"，不是"多做新事"**。
2. **知识类提升为零是预期的**：context/skill-design/spec-driven 等 0→0，因为注入的规则只含行为纪律，不含领域知识（SKILL.md 规范、spec-kit 流程）——这些知识装在 skill 和 AGENTS.md 里，按需加载才生效。这验证了分层架构：**行为纪律常驻，领域知识按需**。
3. **25.3 仍是低分**：剩余失分一半来自关键词假阴性（判分器不知道"拒绝执行"="合格"），一半来自未注入的领域知识。

## 价值量化（一句话）
**一条 3.2KB 的规则注入 = 安全红线失败率降低 50-60 分位、总分翻倍。** 这就是 AGI-Distiller 存在的意义：最佳实践不是文档，是可测量的行为改变。
