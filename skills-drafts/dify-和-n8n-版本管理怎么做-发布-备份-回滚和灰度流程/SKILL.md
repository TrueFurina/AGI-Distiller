# Dify 和 n8n 版本管理怎么做？发布、备份、回滚和灰度流程 — 可执行规则

## 规则

1. 三类版本不混：线上稳定、测试试错、备份回滚
2. 改前必备份，备份必记录
3. 版本命名含场景、日期、版本号、状态
4. 每次发布前写回滚预案
5. 变更记录写5行，不写流水账

## 关联 skill
- deploy-checker（上线检查清单可补充版本管理项）
- version-manager（版本管理）
